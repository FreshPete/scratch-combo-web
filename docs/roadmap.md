# Roadmap

- Verify playback timing on physical audio outputs and test on real mobile devices.
- Run validation on pull requests before merge.
- Discuss the scope of practice audio export before implementation.
- Expand TTM guide coverage where reliable technique references are available.

Playback, count-in, metronome, tempo training, pause and resume, beat trim, and browser-local sessions are available in the hosted app. The [README](../README.md) describes where to find them.

Earlier browser validation reports and screenshots are available in the [repository snapshot before the documentation cleanup](https://github.com/FreshPete/scratch-combo-web/tree/bda5722b20a087fe305f8269b9c26e63273f56dd/docs). Use the current browser tests to verify the current app.
